# CET Master 🎯

> 一款面向四六级考生的智能真题练习与提分系统。

---

## 📖 项目初衷

备考四六级时，我常常面临这样的困境：

- **真题难找**——网上资源零散，下载后还要自己排版打印
- **做了等于没做**——对完答案就丢一边，不知道自己错在哪、弱在哪
- **没有反馈**——不知道自己的水平距离目标还有多远，每天学得焦虑又迷茫
- **缺少个性化指导**——别人的经验帖不一定适合自己，我需要一套属于自己的提分方案

CET Master 就是为**解决这些问题**而生的。

它是一个纯前端应用，打开浏览器就能用。你不需要注册账号、不需要安装软件，所有数据都安全地保存在你自己的电脑里。它为你提供：**完整的真**题练习环境、**即时的答题反馈**、**可视化的成绩追踪**，甚至可以通过 AI **生成专属于你的提分计划**。

---

## ✨ 核心功能

### 📝 完整真题练习

内置 2019–2025 年全部四六级真题，涵盖听力、阅读、写作、翻译四大题型，做完自动评分。

- 选词填空 → 点击单词填入空白，拖拽式交互
- 长篇阅读匹配 → 段落卡片展示，字母按钮选择
- 仔细阅读 → 标准选择题，双击选项中的单词即可查词
- 写作/翻译 → 自带答题区域 + AI 检查评分 + 模板参考

### 📊 成绩单 & 学习分析

每次交卷自动记录分数和时间，生成完整的成绩单：

- 考试次数、平均分、最高分、总正确率一目了然
- 成绩趋势柱状图，直观展示进步曲线
- 一年学习热力图，标记每天的学习活动和考试成绩

### 🤖 AI 提分报告（接入 DeepSeek）

基于你的考试数据，一键生成个性化的提分方案：

- 当前水平评估 + 各题型目标分数
- 每日学习计划 + 备考策略
- 推荐备考资源
- 报告以精美报告单模板呈现，含思维导图和进度条

### 🔍 智能查词 & 生词本

- **双击任意单词**即可查词（包括选项文字）
- 显示英文释义、中文翻译、音标、例句、发音
- 可分类加入生词本（阅读词汇 / 听力词汇 / 写作词汇）
- 所有数据保存在浏览器本地，无需注册账号

### 🎯 语境式复习系统

告别枯燥的单词卡片，把复习放在**真题例句**中完成：

- 例句填空 → 从 4 个形似/易混词中选择正确答案
- 中文选义 → 看释义选单词，双向巩固
- 智能干扰项匹配（内置 80+ 组易混词）
- 间隔递增算法：正确次数越多，下次复习间隔越长

### 📈 仪表盘

- 学习热力图（打卡 + 考试双维度）
- 成绩趋势图
- 单词分类统计
- 连续打卡天数

## 🚀 快速开始

### 方式一：直接使用

用浏览器打开 `index.html` 即可，所有功能完整可用。

### 方式二：本地服务器（推荐）

```bash
python server.py
```

浏览器访问 `http://localhost:8080/`

> 建议使用本地服务器方式，音频播放更流畅。本项目的 `server.py` 支持 HTTP 206 Partial Content（音频拖动进度条）和静默处理连接断开异常，比 `python -m http.server` 更加稳定。

### 启用 AI 提分报告

1. 进入「成绩单」页面
2. 输入你的 DeepSeek API Key（[免费申请](https://platform.deepseek.com/api_keys)）
3. 点击「生成提分计划」即可

## 🛠 技术栈

- 纯原生 HTML / CSS / JavaScript，零依赖
- 数据存储：浏览器 localStorage（数据完全离线，不上传任何服务器）
- 查词 API：dictionaryapi.dev + MyMemory Translation
- AI 引擎：DeepSeek API（可选，需自行申请 Key）
- 音频播放：原生 HTML5 Audio
